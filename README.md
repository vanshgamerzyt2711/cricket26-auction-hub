# Cricket 26 Auction Hub — V2.0.0

For legally purchased copies of Cricket 26 only. We do not support piracy. Cricket 26 is required and not included.

## What's new in V2

- Team Lineups: after completing an auction, open Squads → Edit Team Lineups. Edit all 10 teams independently, with separate Bat First and Bowl First lineups.
- Arrange the starting XI and five substitute/impact options; swap with any retained/bought player from the full squad. Search all squad names and view batting, bowling, fielding and physical game ratings.
- Choose captain, wicketkeeper, first bowler and second bowler. C/WK/1/2 badges show the selected roles. Duplicate players, roles outside the XI, identical opening bowlers and more than four overseas starters are blocked.
- Cricket 26-inspired dark lineup rows, mint selection, player report card and full-squad panel. Save each team/mode, then Review Selected Squads → Apply Squads to Game to import.
- Restore/new-season retention fix: new auctions use the saved starting squad ownership rather than the previous auction's assignments. Successful restore refreshes the starting catalogue. Existing saved seasons keep their own squads and progress.
- Auctioneer voice fix: includes the missing offline Windows speech helper and resolves it from the application folder even when user saves are stored separately. Windows speech/audio availability is still required; audible playback has not been verified on every PC.
- Esc/Menu now opens Resume, Save & Back to Hub, and Save & Quit. Esc closes the active player/pool/squad panel first, or resumes the menu. Completed purchases are saved; an unfinished lot restarts on return.
- Retains Steam/Xbox scan fixes and the startup update screen.

## Updating

V1.0.2 users: open the app → Update & Restart. Settings & Tools → Updates also works. Auction saves and game restore backups are preserved. Users stuck on older scan screens can run the latest Setup.exe once. No paid updater service is required.

All 20 team/mode selections passed profile save, base-game lineup and saved-default-lineup import tests on copies of real Steam saves.
